## 页面与行为

| 页面 | 路由 | 本批行为 |
| --- | --- | --- |
| 概览 | `/dashboard/overview` | 账号窗口、已有 Key、最近本人调用；显式展开测试并选择已有 Key 后进入 Playground |
| 上游账号 | `/upstream-accounts` | 按账号与原生窗口独立观测；选择 Key 后查看该 Key 的近似份额；沿用渠道连接维护入口 |
| API Keys | `/keys` | 卡片、筛选、暂停/恢复、复制、分额编辑；保留原有高级维护入口 |
| 调用记录 | `/usage-logs/common` | 本人记录、时间与 Key 筛选、桌面详情和手机返回；成功与用量证据分别显示 |
| 个人资料 | `/profile` | 本人身份、只读管理范围、界面偏好、折叠安全设置；加载超时、失败和手动重试 |

共享外壳保留原 M logo，桌面深色侧栏、柔和蓝色选中态与手机四项底栏。个人主流程隐藏金额、余额和充值，商业模式兼容入口保留。完整回答缺 usage 仍显示请求成功，输入/输出 Token 均为未知；估算用量不冒充上游真实用量。

## 数据来源与边界

- 当前身份与渠道读取权限由 `/api/user/self` 确认；窗口来自 `/api/channel/quota/changes?range=24h&limit=100&sort=observed_desc`。仅原生百分比窗口参与显示，多个窗口分别表达，不相加、不从 Token 换算。超过 300 秒标陈旧，缺失/非法证据保留未知。
- 已有 Key 来自分页 `/pg/keys`，读取不要求 Key 明文；显式聊天交接绑定当前用户与会话，失效后重新选择。最近调用来自本人 `/api/log/self`，概览取首 10 条记录中的最多 5 条相关调用，并非全历史统计。
- 分额来自 `/api/token/:id/subscription-share`，编辑沿用原接口、CAS 和操作标识。Root 只读视图的 `channel_id` 用于准确关联账号，普通 owner 不返回该字段；无数据库结构变更。
- 100% 是明确账号的明确原生窗口总池。同池总分额不超过 100%，0% 停止后续新请求；调整比例保留已有估计用量，不预留上游容量。单次、并发、在途请求和采样延迟均可能造成超额，重置依赖可信新周期证据。
- 当前 API 提供选中 Key 与全池汇总，未提供全池逐 Key 分解和独立的启用前占用字段；页面不填入设计示例、不把整体占用或未归属增长冒充这些字段。没有准确逐 Key 归因或准点自动恢复承诺。
- 原 Key 新建/编辑/访问范围/删除等维护功能保留；这些高级流程的完整视觉重做、账号改绑和窗口重选仍属于后续设计范围。
