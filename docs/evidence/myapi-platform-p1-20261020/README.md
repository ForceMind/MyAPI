## 首轮行为与验证范围

- 默认空首页采用新入口；已有 HTML/Markdown/URL 自定义首页保留。已登录访问空默认首页进入总览。
- PC 按业务分组、可收起；小于1024px用移动导航和“更多”。同一功能登记经过角色、模块和 channel.read 过滤。移动端也可进入内容/绘图/异步日志、系统信息与设置。
- 原 admin/self 日志接口、服务端筛选和分页恢复。提交筛选和重置保留 pageSize；详情/保存内容弹层关闭后保留原筛选和页码。日志类型过滤不伪称跨页请求结果过滤。
- 请求结果、用量可信度、结算状态分离。明确已完成即成功；未提供 usage 为未知，明确报告零为零。历史未决账务不修改。
- 金额列、费用明细、日志内嵌套用户余额隐藏。RPM/TPM 明确仅统计最近60秒的消费日志，不能当作全部请求或完整 Token 用量。
- 跨查询范围不沿用上一权限数据；更换用户/角色/SID 关闭旧详情。认证层继续清理旧会话查询缓存。客户端关闭不保证已接收的服务端读取被取消。
- 内容按需读取现有脱敏存储，保留大小/截断边界与实际 HTTP 状态；只读 SSE 历史不重发请求。不自动启用采集、刷新供应商或重试生成。

本机中间验证包含 37 项初批、11 项闭环/导航、34 项日志关键回归和修订27项，彼此存在重叠，不累计为独立测试数量。最终以准确 CI 的完整测试数和实际浏览器报告为准。最新本机类型检查、lint 无错误；原有未触及文件的 warning 保留。
