## 本轮可操作行为

- 默认空首页采用 MyAPI 新入口；已有 HTML/Markdown/URL 自定义首页保留。已登录访问空默认首页进入总览。
- PC 采用可收起的分组侧栏；小于 1024px 使用移动底部导航和“更多”。共用功能登记，经过角色、模块和 `channel.read` 过滤，手机也能进入内容/绘图/异步日志、系统信息与设置。
- 恢复原 admin/self 日志接口、服务端筛选和分页。提交/重置保留 pageSize，详情/内容关闭后保留筛选与页码；日志类型筛选不伪称请求结果全局筛选。
- PC 首列提供 Request ID、第二列提供详情；手机使用独立记录卡片。请求结果、用量可信度和结算状态分开：明确完成仍成功，缺 usage 为未知，明确报告零为零；历史未决账务不修改。
- 个人资金模式隐藏金额列、费用明细和嵌套用户余额。RPM/TPM 标明仅统计最近 60 秒消费日志，不代表全部请求或完整用量。
- 切换查询范围不沿用上一权限数据；更换用户、角色或 SID 关闭旧详情，认证层继续清理旧会话缓存。客户端关闭不保证已接收的服务端读取取消。
- 内容按需读取已有脱敏存储，保留大小/截断边界与实际 HTTP 状态。读取 JSON/SSE 历史不会重发模型请求，不启用采集或刷新供应商。

## 隔离预览与运行边界

[控制台](http://127.0.0.1:4181/__preview/operator) · [调用记录](http://127.0.0.1:4181/usage-logs/common?pageSize=20) · [公开首页](http://127.0.0.1:4181/__preview/guest)

4181 使用准确 CI 工件及纯内存合成 API，显式显示隔离标记，业务写操作拒绝。没有真实数据库、Redis、凭据或供应商转发路径；模拟 auth refresh 不是真实 OAuth/凭据刷新。工件 200 文件的 SHA256 清单与服务主 JS 已核对。注入的预览标记使服务 HTML 与原工件 index 不同，差异记录在探针中。

进程与 `/tmp` 文件依赖会话；恢复先核对端口、revision 和工件 SHA。预览不代表生产部署。当前线上 beta.21 不动，本批未新增真实供应商测试，不写生产数据/备份/Redis，不改 Key 身份或轮换/迁移门槛。维护者两份 WIP 文档哈希保持原值，未暂存或提交；旧部署资料及设计草稿保留。
