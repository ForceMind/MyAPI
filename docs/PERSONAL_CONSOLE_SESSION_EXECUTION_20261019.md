## 验收、风险和停止条件

- 相同用户的新 SID、角色或用户变化以及组件卸载后，旧操作不再发后续请求、发布旧反馈、写当前缓存或复制迟到秘密；401不刷新/不重放。正常同会话成功路径保持；其他非本片调用的默认刷新有正例。
- 删除/预算/策略/分额的幂等、未知结果和写锁语义保持，绝不为测试删除业务保护。重复点击只允许一次有效提交。
- 修改前端必须通过相关测试、类型和涉及文件 lint；文案变化才按 i18n 技能完成七语言及同步。页面版本入口一致。
- 必须有准确源码 CI、实际运行页面、桌面/手机图与独立审查；限制如实记录。新发现需要凭据/真实服务商、历史操作、扩大后端资格或部署时停止该依赖，继续本片可独立工作。
