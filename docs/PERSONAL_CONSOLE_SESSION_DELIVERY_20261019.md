## 行为与保留范围

当删除、预算或 Key 访问策略的旧请求返回401时，先前统一客户端可能刷新认证并借当前会话重放。本批在这些维护入口关闭自动认证重放；账号、角色、登录会话SID变化或组件卸载后，旧响应不再刷新/关闭当前面板、清除当前选择、发布通知或写入当前缓存。正常同会话操作保持。

- 单删与批删使用同步提交守卫，只发一次；发送时固定目标ID，完成后复核会话。新增可选API配置保留其它旧调用的默认行为。
- 预算组件及缓存按用户、角色、SID和Key隔离，读取不复用其它请求，旧读写取消或迟到时不接受结果。关闭全局业务错误通知，错误继续在面板内展示。原有未知结果写锁、同一operation重试、预算/recover权限与业务算法保持。
- Key assigned access 的read/save/remove/preview及owner读取禁止自动认证重放，保留既有会话前后校验和取消。共享API的用户级策略仍保留原默认刷新行为，并有正例保护。
- 分额此前已在beta.17具备相同保护，本片没有修改。休眠旧workbench hook只有测试引用，不将其推断为运行缺陷或纳入重构。

沿用已确认 visual-v0.2、原M及柔和蓝。没有新增UI文案或locale键；本片没有Go、schema、计费、额度/分额算法或轮换资格变化。完整回答缺usage仍成功、Token未知；个人主流程不显示金额余额。已接收操作仍可能在服务端完成，客户端取消不保证回滚。
