# v0.2.0-beta.13 开发候选

本版本按维护者指示先收口个人核心流程，再推进 Key 共享百分比。历史账务继续冻结，
新版本暂不部署，不创建标签、Release 或 GHCR 版本镜像。当前私有 beta.12 服务不在本批写入范围。

本批修复个人工作台与 Playground 之间的 Key 选择交接：查看并选择 Key A 后进入聊天页，
不能沿用先前保存的 Key B。交接由明确点击触发，绑定用户和会话，并重新校验本人可用 Key；
失败或失效保持空选，不自动发送请求。普通直接打开聊天页的已有配置仍按原合同恢复。
补齐工作台七语言手机/桌面及两 writer 隔离应用流程。具体状态和准确验证见
[个人核心执行记录](PERSONAL_CORE_CLOSURE_EXECUTION_20261014.md)。当前记录为实施目标，未声明验收通过。

既有账户窗口剩余百分比保护阈值不等于逐 Key 共享分额。共享百分比的总池、计量和结算来源
尚待明确，本候选不能把共享账户变化算作某一个 Key 的消耗。更多协议硬预算、真实 provider/OAuth/
窗口429/费用稳定资格和历史恢复仍按原证据范围处理。

源码默认镜像引用仅为版本准备，`ghcr.io/forcemind/myapi:v0.2.0-beta.13` 尚未发布，不能直接拉取。
云端 push=false 的隔离测试镜像不属于发行或部署。beta.10 标签及历史镜像保持不可变。
